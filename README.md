## Featured Projects

### HR Hub – Intelligent Compliance
Live compliance platform automating I-9 management for 1,300+ employee records across 11 campuses at Austin Community College. Reduced audit preparation from days to hours.
- Real-time I-9 Builder for List A, B, and C documents
- USCIS M-274 handbook guidance
- EAD Extension & Receipt Rule verification
- Automated Section 3 reverification workflows

**Live:** [visadata.netlify.app](https://visadata.netlify.app)

### I-9 Compliance Hub
Tracks EAD expirations across F-1, H-1B, H-4 EAD, and C33 visa categories. Zero missed reverification deadlines since deployment.

### GRC Automation Pipeline
Replaced a 3-day manual audit process with an automated Python pipeline generating audit-ready compliance dashboards in minutes. Mapped to NIST 800-53 and HIPAA control families.

### SOC Lab – Security Monitoring
Enterprise-grade security monitoring using Elastic Stack SIEM and pfSense across a three-zone network architecture mapped to MITRE ATT&CK.

**Live:** [securityflavor.netlify.app](https://securityflavor.netlify.app)
